# What is ICT
ICT Information and Communication technology is the basis through which the world has become the global village. ICT is present almost everywhere from our homes to our offices, schools, communication, business everywhere. ICT includes
-  Computers
-  Networks
-  Internet
-  Applications
-  Home Appliances
